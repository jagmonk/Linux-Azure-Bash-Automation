# Interview Talking Points

## STAR answer

### Situation
I supported hybrid infrastructure across Microsoft 365, Entra ID, Windows Server, Linux, networking, backup, endpoint management, and data center operations.

### Task
I wanted a practical automation portfolio that showed cloud-aware Linux administration, not just local server checks.

### Action
I built Bash scripts that integrate with Azure CLI, Azure Resource Graph, Azure Storage, Recovery Services vaults, Key Vault, Network Watcher, Defender for Cloud, and Managed Identity. I structured each script with safe defaults, logging, CSV or JSON output, and operational documentation.

### Result
The portfolio demonstrates senior Systems Administrator skills in hybrid cloud operations, reporting, troubleshooting, backup validation, security hygiene, and cost governance.
